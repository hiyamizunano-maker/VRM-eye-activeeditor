# VRM ハイライトリアクティブ調整 v6

VRM 0.xモデルの瞳全体とハイライトを、Blink系Expressionへ連動させる小さなブラウザツールです。

**公開アプリ:** https://hiyamizunano-maker.github.io/VRM-eye-activeeditor/

VRMは通常利用時にサーバーへアップロードされません。読み込み、プレビュー、編集、書き出しはブラウザ内で行います。外部ライブラリを取得するため、ページ表示時のみCDNへ通信します。

## v6の主な機能

- `Blink` / `Blink_L` / `Blink_R`へ瞳全体の拡大縮小を反映
- Blink時のハイライト倍率を0～200%で設定
- Blink / EyeWideに連動するハイライト移動量を調整
- 自動まばたきと手動ボタンによるプレビュー
- 元VRMを上書きしない別名保存
- 既存GLB/VRM構造を保持し、対象モーフのPOSITION差分だけを局所変更

瞳孔だけを変形する専用モーフ機能は使用しません。瞳全体は左右それぞれの中心を基準に拡大縮小します。

## 使い方

1. Chromeで公開アプリを開きます。
2. VRM 0.xファイルをドラッグ＆ドロップするか、ファイル選択から読み込みます。
3. 瞳とハイライトの対象マテリアルを確認します。
4. 見開き・通常・閉眼で変化を確認します。
5. 瞳全体倍率、ハイライト倍率、揺れの強さを調整します。
6. 「調整済み設定を別名VRMとして保存」を押します。
7. 保存したVRMを実際に使用するアプリでも確認します。

## 調整時の注意

- 元から瞳が大きいモデルは、見開き時の瞳全体倍率を100%のまま使うことを推奨します。
- ハイライト倍率を大きくしすぎたり、揺れの強さを上げすぎたりすると、まぶたや目の輪郭からはみ出す場合があります。
- 見開き・通常・閉眼の各状態をプレビューしてから保存してください。
- モデルの構造によっては、対象マテリアルを手動で選ぶ必要があります。
- 独立したハイライト用ジオメトリまたはマテリアルを持たないモデルでは、意図した結果にならない場合があります。

## 維持するデータ

本ツールは次のデータを削除・再生成しません。

- A / I / U / E / Oなど既存Expression
- PerfectSync関連Expression
- Spring Bone / Collider
- Material / Texture
- VRM extensionとその他の既存extension

モデルごとに内部構造が異なるため、すべてのアプリとの互換性を保証するものではありません。元VRMを保管し、利用先アプリで最終確認してください。
