# VRM 目まわりリアクティブ調整ツール

VRM 0.xモデルの「瞳」と「ハイライト」の動きを、ブラウザ上で確認しながら調整し、VRMへ書き出すためのツールです。  
VRoid Studio製VRMを主な対象として、既存の表情やPerfectSync設定をできるだけ維持したまま、目まわりのモーフ差分のみを追加・調整します。

---

## 主な機能

### 閉眼時の瞳縮小
- `Blink` / `Blink_L` / `Blink_R` に連動して、目を閉じる際に瞳を小さくします。
- 縮小率はツール上で確認しながら調整できます。

### 見開き時の瞳拡大
- PerfectSyncの `EyeWideLeft` / `EyeWideRight` に連動して、目を見開いた際に瞳を大きくします。
- ※PerfectSyncのEyeWideモーフを持たないVRMでは、この機能は適用されません。

### ハイライト移動
- BlinkおよびEyeWideに合わせて、瞳のハイライトへ小さな位置変化を追加できます。
- ハイライトの移動量はプレビューを確認しながら調整できます。
- ハイライトは物理演算ではなく、各表情モーフ内の頂点差分として保存されます。

---

## 変更しないもの
本ツールは、目まわり以外の既存モーフをできるだけ変更しない設計です。特に以下は変更対象にしません。
- A / I / U / E / O の口形
- その他のPerfectSync表情
- 眉・口などの既存表情
- SpringBone / Collider
- 既存マテリアル設定

*※ただし、VRMの構造はモデルによって異なるため、すべてのVRMで完全な互換性を保証するものではありません。*

---

## 使い方
1. HTMLファイルをブラウザで開きます。
2. 調整したい `.vrm` ファイルを読み込みます。
3. 瞳やハイライトの対象を確認します。
4. Blink・EyeWideなどのプレビューを確認します。
5. 各スライダーで瞳の大きさやハイライト移動量を調整します。
6. 問題がなければ、調整済みVRMを書き出します。
7. VSeeFace、Luppetなど、実際に使用するアプリでも動作を確認してください。

*※元VRMは残し、まずコピーしたモデルで動作確認することを強く推奨します。*

---

## プレビューについて
ツール上の表示は、可能な限り書き出し後のVRMと同じ頂点変形方式で表示します。  
ただし、使用するVRMビューア・トラッキングソフト・シェーダーなどによって、実際の表示には多少の差が生じる場合があります。最終確認は、実際に使用するアプリ上で行ってください。

## ハイライトについて
本ツールでVRMへ保存されるハイライトの動きは、Blink / EyeWideに連動したモーフ変形です。  
SpringBoneのような「遅れて追従する」「揺れてから戻る」「慣性で振動する」といった物理的な「揺れ」を、標準VRMのモーフとして保存するものではありません。

---

## 対応形式
- VRM 0.x
- VRoid Studioから書き出したVRM
- PerfectSync対応VRM  
*※モデルの構造によっては、対象マテリアルやモーフを手動で選択する必要があります。*

---

## 利用上の注意
### VRM・モデル・素材の利用規約を必ず確認してください
本ツールを使用してVRMを改変する場合は、使用するVRMモデルおよび関連素材の利用規約を必ず確認し、その条件に従ってください。
- モデルの改変が許可されているか
- 改変モデルの使用条件
- 商用利用の可否
- 再配布の可否
- クレジット表記の要否

本ツールを使用できること自体が、第三者が制作したモデルや素材の改変許可を与えるものではありません。モデル・素材の権利者が定めた利用条件を優先してください。

### ファイルの取り扱い
VRMファイルの読み込み・処理はすべてブラウザ上（ローカル）で行います。  
本ツール自身には、読み込んだVRMを外部サーバーへアップロードする機能はありません。  
*(ただし、外部JavaScriptライブラリを取得するため、ページ読み込み時にCDNへの通信が発生します)*

### 安全のために
- 重要なモデルを直接使用せず、バックアップまたはコピーしたVRMで試してください。
- 調整値を極端に大きくすると、瞳やハイライトが本来の位置から外れる場合があります。
